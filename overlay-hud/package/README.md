# OverlayHUD 26.11.3 — Native + Electron

Локальный HUD для **R.E.P.O.** с двумя режимами: прозрачное окно Electron
(**по умолчанию**) и Unity HUD внутри игры (Native).

**Автор: EgorSalad.** Неофициальный фанатский проект, не связанный с semiwork,
издателем R.E.P.O. или Thunderstore.

## Что нового в 26.11.3

Обновлено комплектное Electron-приложение: подсказки используют официальные
русские и английские названия, в том числе для монстров без собственной иконки.
Альтернативная сборка Native обновлена до той же версии 26.11.3.

Перед обновлением закройте игру и уже запущенный OverlayHUD (Electron).
Изменение SHA-256 `OverlayHUD_app.zip` запускает управляемое обновление приложения
при следующем desktop-автозапуске с сохранением корневого конфига и таймкодов.

## Возможности

- Встреченные монстры, здоровье, требуемая сила, количество в группе и респавн.
- Уровень и таймер, улучшения игрока, стоимость ценностей и потери.
- Волны близости, числа урона, уведомления об уничтожении предметов.
- Русский и английский языки, официальные игровые названия в подсказках.
- Настройка положения, масштаба, рядов, колонок и видимости элементов.
- Локальные текстовые таймкоды уровней.

По умолчанию монстры раскрываются только после встречи. Для точного респавна
и синхронизации ХП в мультиплеере актуальный OverlayHUD нужен у хоста и клиентов.
Числа урона показывают потерю ХП от любых источников, не персональный урон игрока.
Синхронизацию ХП версии 26.11.3 необходимо проверить в игровом лобби перед публикацией.

## Установка и выбор сборки

1. Установите BepInExPack для R.E.P.O. в профиль r2modman/Gale.
2. Импортируйте `EgorSalad-OverlayHUD-26.11.3-Full.zip` как локальный мод,
   без предварительной распаковки.
3. Запустите игру с модами и дождитесь установки и запуска `OverlayHUD.exe`.

Для ручной установки распакуйте файлы пакета в `BepInEx/plugins/OverlayHUD/`.
Архив `OverlayHUD_app.zip` должен оставаться рядом с DLL. Node.js и Electron
отдельно устанавливать не требуется.

Есть альтернативный пакет `EgorSalad-OverlayHUD-26.11.3-Native.zip`: только Unity HUD,
отдельная DLL без desktop-кода, HTTP-моста, архива приложения и его настроек.
**Это тот же плагин: не устанавливайте оба варианта вместе.** При смене сборки
закройте игру и приложение, сохраните нужные таймкоды и удалите прежний пакет целиком,
не оставляя вторую DLL или остатки приложения в каталоге мода.

При переходе со старых версий или между сборками сохраните резервную копию и удалите
`BepInEx/config/local.overlay.overlay_hud.cfg`. При следующем запуске создаётся
чистый конфиг. Старые секции и значения не мигрируют; настройки задайте заново.

## Конфигурация

Файл: `BepInEx/config/local.overlay.overlay_hud.cfg`.
В Full по умолчанию:

```ini
[01 General]
Renderer = Electron
```

Для HUD внутри игры замените значение на `Native` и перезапустите игру.
Native не запускает приложение и не отправляет HTTP-запросы. При ошибке создания
Native HUD Full пишет причину в лог и возвращается к Electron на текущую сессию.

| Секция | Настройки по умолчанию |
| --- | --- |
| `01 General` | `Renderer = Electron`; альтернатива `Native`, смена требует перезапуска |
| `02 Detection` | `ScanIntervalSeconds = 3`, `StatusIntervalSeconds = 10` (минимум 10), `RequireLineOfSight = true`, `RevealUnknownMonsters = false`, `PreferPlayerVisionDetection = true` |
| `03 Native - General` | `Enabled = true`, `Language = ru` (или `en`), `SaveTimestamps = true` |
| `04 Native - Layout` | `Alignment = Center`, `Scale = 1`, `OffsetX = 0`, `OffsetY = 20`, `HorizontalLayout = true`, `HorizontalColumns = 11`, `Columns = 4`, `MonsterSize = 70`, `UpgradeSize = 38`, `UpgradeRows = 2`, `WrapValueLabels = true` |
| `05 Native - Information` | `ShowLevel`, `ShowTimer`, `ShowMapValue`, `ShowLostValue`, `ShowUpgrades` — все `true` |
| `06 Native - Monsters` | `ShowMonsters`, `ShowHealth`, `ShowRespawnTimer`, `ShowRespawnIndicator`, `ShowStrength`, `ShowMonsterCounts` — `true`; `OnlyAliveMonsters`, `FilterUndetectedMonsters` — `false` |
| `07 Native - Effects` | `Animations`, `ShowProximityWaves`, `ShowDamageNumbers`, `UseGameUIEffects` — `true`; `ShowDestroyedItemAlerts`, `ShowTooltips` — `false` |
| `08 Native - Upgrades` | Все 12 переключателей — `true`, список ниже |
| `09 Electron - App` | `AutoStart = true`, `AutoClose = true`, `ExecutableRelativePath` — пусто, `ArchiveName = OverlayHUD_app.zip` |
| `10 Electron - Connection` | `Endpoint = http://127.0.0.1:8787/api/monster-seen`, `LevelEndpoint = http://127.0.0.1:8787/api/level` |
| `99 Diagnostics` | `Logging = false` |

Native-only не создаёт секции `01`, `09`, `10`. Старые секции конфига не поддерживаются.

### Native: настройка внутри игры

- Секции `03`–`08` применяются на лету через BepInEx Configuration Manager или
  перезагрузку конфига средствами BepInEx. Автоматического наблюдения за cfg нет:
  после ручного редактирования перезагрузите конфиг либо игру.
- `Enabled` скрывает HUD, не останавливая отслеживание и таймкоды.
- `Alignment`: `Left`, `Center`, `Right`; `OffsetX` смещает от горизонтальной привязки,
  `OffsetY` задаёт отступ сверху. `Scale` — 0.5–2 относительно 1920×1080.
- `HorizontalLayout=true` использует `HorizontalColumns`, `false` — `Columns`.
  Диапазон 1–24; лишние монстры переносятся на следующий ряд, а не скрываются.
- `MonsterSize` — 32–128, `UpgradeSize` — 20–64 до общего масштаба;
  `UpgradeRows` — 1 или 2. `WrapValueLabels` размещает подписи над суммами.
- `ShowHealth` управляет полосками ХП. Числовой таймер и круговой индикатор респавна
  независимы. Сила: зелёный — хватает, красный — нет, `X` — нельзя поднять, `?` — нет данных.
- `OnlyAliveMonsters` скрывает погибших встреченных монстров; только вместе с ним
  `FilterUndetectedMonsters` дополнительно скрывает погибшие необнаруженные заглушки.
- `Animations=false` также отключает волны, вспышки и числа урона; таймеры продолжают работу.
- `UseGameUIEffects=true` включает экспериментальные эффекты игровой UI-камеры.
  Может снижать резкость. Для подсказок отключите его, включите `ShowTooltips`
  и разблокируйте курсор средствами игры. HUD не разблокирует и не захватывает курсор.
- В `[08 Native - Upgrades]`: `strength`, `tumbleLaunch`, `range`, `sprintSpeed`,
  `tumbleWings`, `crouchRest`, `extraJump`, `tumbleClimb`, `health`, `stamina`,
  `mapPlayerCount`, `deathHeadBattery`. Отдельный тип виден, если получен и включён `ShowUpgrades`.

Native скрывается при карте и счётчике квоты независимо от положения.
Шрифты и иконки встроены в DLL; символы вне ASCII и поддерживаемой кириллицы
заменяются на `?`. Настройки Electron не импортируются в Native.

### Electron: окно и управление

Используйте оконный или borderless-режим игры, не exclusive fullscreen.
Оверлей поддерживает перетаскивание, привязку к краям/центру и панель настроек.

| Клавиши | Действие |
| --- | --- |
| `Ctrl+Alt+O` | Показать/скрыть окно |
| `Ctrl+Alt+I` | Включить/выключить пропуск кликов |
| `Ctrl+Alt+R` | Перезагрузить страницу |
| `Ctrl+Alt+Q` | Закрыть OverlayHUD |

ПКМ по значку в трее: монитор, язык, взаимодействие, сохранение таймкодов,
скриншот HUD на прозрачном фоне и аппаратное ускорение с перезапуском приложения.
Оверлей скрывается при карте в любом положении, при счётчике квоты — только при
привязке к верхнему краю. Сервер слушает `127.0.0.1:8787`, телеметрии нет.

`AutoClose=true` закрывает автоматически запущенное приложение после выхода/краша
игры, включая перезапуск приложения при смене аппаратного ускорения. На запуск
вручную это правило не распространяется. Пауза и загрузка не считаются выходом.

## Хранение и обновление приложения (Full)

При пустом `ExecutableRelativePath` в `[09 Electron - App]` приложение устанавливается в:

```text
%LOCALAPPDATA%\OverlayHUD\profiles\<profile-key>\app\OverlayHUD.exe
```

`<profile-key>` — SHA-256 нормализованного `BepInExRootPath`. Файлы приложения,
корневой `overlay-config.json` и `timestamps/` изолированы по профилям BepInEx;
Electron `localStorage` остаётся в существующем хранилище, без новой изоляции.
Пользовательский путь к EXE считается от DLL либо задаётся абсолютным;
автоматический внешний перенос к нему не применяется.

Перед обновлением закройте **игру и приложение**. При desktop-автозапуске распознанная
старая папка `OverlayHUD_app` рядом с DLL переносится целиком, включая конфиг,
таймкоды и неизвестные файлы. Не удаляйте её заранее: удаление происходит только
после успешного переноса. Если старая и внешняя установки существуют одновременно,
старая остаётся нетронутой, а лог предупреждает о необходимости ручной проверки.
Блокировки при очистке также записываются в лог.

Изменение SHA-256 архива запускает обновление через промежуточную папку с сохранением
корневого конфига и таймкодов. Ошибка сохраняет исходную установку и отменяет запуск.
Перенос файлов не означает миграцию старых секций BepInEx-конфига.
Native не запускает перенос. Для переноса достаточно новой DLL и существующего
комплектного архива; пересборка приложения не нужна.

Внешние файлы переживают удаление мода/профиля. Для полной очистки закройте приложение,
сохраните нужные файлы и вручную удалите соответствующий каталог `<profile-key>`.

## Таймкоды

- Native: `BepInEx/plugins/OverlayHUD/timestamps/`, переключатель `SaveTimestamps`.
- Electron: `timestamps/` рядом с фактически запущенным EXE; по умолчанию во внешней
  установке выше. Переключатель **Прочее → Сохранять таймкоды** в трее.

Один UTF-8 файл на сессию: местное время начала уровня, номер, карта, встреченные
монстры и их количество. Язык новых строк соответствует выбранному языку HUD.
Отключение завершает текущую строку; повторное включение возобновляет запись
со следующего уровня, без удаления старых файлов.

## Диагностика

Лог активного профиля: `BepInEx/LogOutput.log`. Ищите `Loading [OverlayHUD`,
`Native HUD initialized`, `Bundled OverlayHUD desktop app ready at:` и предупреждения.

- Native: проверьте `Renderer`, `Enabled`, загрузку игрового уровня и ошибки инициализации.
- Electron: проверьте оконный/borderless-режим, свободный порт `8787`, архив рядом с DLL
  и фактический путь EXE в логе. При чёрном фоне отключите аппаратное ускорение в трее.
- Для подробного лога включите `Logging=true` в `[99 Diagnostics]`.
- Не оставляйте две копии плагина. Приложите свежий лог и конфиг к отчёту об ошибке.

Обновления игры и другие моды могут влиять на детекцию, стоимость и UI.
Полная документация, исходники и сборка пакетов: https://github.com/Dunweir/overlay_repo
